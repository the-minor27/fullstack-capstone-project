# GiftLink User Stories

## User Story 1
As a user, I want to register an account so that I can access GiftLink.

## User Story 2
As a user, I want to log in securely so that I can access my account.

## User Story 3
As a user, I want to create a gift listing so that I can give away household items I no longer need.

## User Story 4
As a user, I want to browse available items so that I can find things I need for free.

## User Story 5
As a user, I want to search for items by keyword so that I can quickly find relevant gifts.

## User Story 6
As a user, I want to filter items by category so that I can find specific types of items.

## User Story 7
As a user, I want to view item details so that I can learn more about an available item.

## User Story 8
As a user, I want to add comments to items so that I can communicate with other users.

## User Story 9
As a user, I want to edit my profile so that my personal information stays up to date.

## User Story 10
As a user, I want to update or remove my listings so that I can manage the items I have posted.
